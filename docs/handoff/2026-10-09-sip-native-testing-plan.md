## 2. Phase B — Local "real-stack gate" command (short and effective)

Before §3 lands, the maintainer's local convention:

```bash
make m2-platform-resip-build
AS_REQUIRE_NATIVE_EXTENSIONS=1 make gate
# or explicitly:
AS_REQUIRE_NATIVE_EXTENSIONS=1 uv run pytest -m "unit or contract" -q
```

With `AS_REQUIRE_NATIVE_EXTENSIONS=1`, a missing extension **fails** instead of being skipped (`platform/tests/native_extensions.py`).
