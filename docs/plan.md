The design baseline is [`architecture/system-architecture.md`](architecture/system-architecture.md).
This document is the plan built on top of it.

### 2.2 The three POC defects this structure removes, and how

| POC defect | Mechanism here |
|---|---|
| Every build job needed `git clone ../as_platform` | One repository, one `uv sync`, no sibling-directory checkout |
| `deploy/Dockerfile.as` failed: the build context was outside the repository | Everything sits under one root |
| `VERSION` 0.2.0 vs `pyproject` 0.1.0 | `tests/test_version_consistency.py` —— one number, one home, guaranteed by an assertion |

### 2.3 The guards delivered together with the skeleton

Layering is not enforced by directory layout —— in a monorepo any import resolves successfully. It is enforced by tests:

| Guard | Assertion |
|---|---|
| `platform/tests/test_library_independence.py` | The kernel imports no app, service or testbed package; the forbidden list covers every other workspace member |
| `tests/test_workspace_layout.py` | All declared members exist, one package each under `src/`, distribution names are unique, ruff `src` is complete, members declare no tool configuration of their own, and no member owns a `VERSION` file |
| `tests/test_version_consistency.py` | `VERSION` is SemVer, the latest CHANGELOG title equals it, and every component version is SemVer |

| Layer | Marker | Trigger |
|---|---|---|

| ② integration | `integration` | after ① |
| ③ e2e | `e2e` | after ② |
| ④ performance | `performance` | on demand / manual |

## 6. The working rules that shaped this plan

- **Screen first, then adopt** ([`migration/triage.md`](migration/triage.md)) —— the POC is the source of behaviour, not the source of code.
- **Write the ADR together with the change**, never afterwards and never in batches.
- **TDD is mandatory at the decision layer**; the protocol layer uses contract plus simulation tests (ADR-0015).
- **The POC is not a dependency.** Nothing here may reference `../3rtparty_AS_POC` or `../as_platform`.
- **AI-generated code passes exactly the same gate** and is marked as AI-generated in the PR (AGENT.md §AI assistance).
- **No capacity number is published before M6.**
