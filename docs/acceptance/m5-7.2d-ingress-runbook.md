## Check items (must tick before close)

| # | Item | Verification method |
|---|------|---------------------|
| 1 | Controller keeps default `nginx.ingress.kubernetes.io` annotation **prefix** | `kubectl describe ingress` shows annotation key names |

## M5-1d — external PostgreSQL (kind)

| Step | Description |
|------|-------------|
| Start DB | `deploy/compose` `postgres:12.22`, published port default **55432** (same roles/init as M5-0b integration) |
| Runtime DSN | Secret `as-config-runtime`'s `AS_CONFIG_DSN` uses **`as_config_web`** (not owner); **do not** put owner DSN into the runtime Secret |
| kind network | Pod accesses host PG: `postgresql://as_config_web:…@<docker-gateway>:55432/as_config` (`m5-lib.sh` auto-takes `as-m5-control-plane` gateway) |
| Migration | if DB is empty, first run `as-config-migrate` (owner DSN, manual); when compose init already created the role, usually only schema consistent with M4b is needed |

Placeholder DSN `postgres:5432` is **only an in-cluster Service name**; when compose is not loaded into kind it will **CrashLoop**; Ingress objects can still be created, but **Ready evidence** depends on M5-1d.

## Corporate HTTP proxy

When `http_proxy` is set, host `curl localhost` goes through the proxy → **403/000**. To verify config-service: `NO_PROXY=127.0.0.1,localhost kubectl port-forward` or `make m5-kind-verify`.

## Host 80/443 and in-cluster ingress curl

By default `m5-kind-up.sh` does **not** map hostPort 80/443. Some kind environments produce an **empty reply** (curl 52) for in-cluster HTTP to the ingress Controller.

| Scope | Requirement |
|-------|-------------|
| **M5-1c / §4.5 slice evidence** | Ingress object + annotations (table items 1–3, 6) + config-service **Ready**; `make m5-kind-verify` **port-forward HTTP 200** |
| **M5 maintainer sign-off / §217③ / M4b-7.2d close** | **must** complete table items **4–5** (301/308 via ingress or equivalent + browser HTTPS-only); port-forward **cannot** substitute. On kind use `extraPortMappings` or customer ingress collection; empty reply counts as **failed**, fix the environment or switch collection path, **do not** tick 7.2d close in the plan |
